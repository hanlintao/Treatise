# Treatise 写作平台 使用文档

本项目是一个面向学术写作的全栈工作台，集成章节写作、参考文献、知识体系、论文阅读、灵感与随笔、语音速记、内部动态等功能，适合长期研究型图书编写与资料管理。

---

## 技术栈

| 类别 | 技术 |
| --- | --- |
| 前端框架 | React 19 |
| 构建工具 | Vite (Rolldown) |
| 样式 | Tailwind CSS 4 |
| 路由 | React Router 7 |
| 拖拽排序 | @dnd-kit |
| 图表与可视化 | ECharts 5 · ECharts GL · vis-timeline · ReactFlow |
| 后端 | Express 5 (Node.js) |
| 实时通信 | WebSocket (ws) |
| 文件处理 | Multer · Archiver |
| OCR 脚本 | Python (PaddleOCR) |

---

## 1. 快速开始

### 1.1 环境要求
- Node.js 18+ (建议 18/20 LTS)
- npm 或 pnpm
- macOS / Windows / Linux 均可

### 1.2 安装与启动
```bash
npm install
npm run dev
```

默认启动：
- 前端：`http://localhost:8000`
- 后端：`http://localhost:3001`

### 1.3 构建与预览
```bash
npm run build
npm run preview
```

## 2. 数据与存储结构

### 2.1 数据文件
所有数据以文件形式存储，便于备份、迁移和版本控制：
- 章节内容：`src/content/*.md`
- 章节元数据：`src/data/chapter_meta.json`
- 参考文献：`src/data/references.json`
- 知识体系：`src/data/knowledge.json`
- 笔记、灵感、语音、微博等：`src/data/*.json`

### 2.2 附件与媒体
- 论文 PDF：`public/papers/{refId}/`
- 知识点图片/附件：`public/knowledge/`
- 语音记录：`public/assets/audio/`

### 2.3 一键备份
侧边栏「知识管理」分组下的「数据备份」按钮会下载全量 ZIP 包（包括内容与数据）。

## 3. 核心功能概览

### 3.1 章节写作与阅读（Reader）
- Markdown 编写，支持编辑/预览切换
- 章节自动保存（防止丢失）
- 大纲视图（基于标题结构）
- 思维导图视图（H1-H3 自动生成）
- 章节笔记面板（与章节绑定）
- 引用插入与预览
- 选中文本后出现的 AI 操作菜单（润色、扩写、解释、抽取参考文献）
- 图片上传并自动插入到正文
- 章节内知识点匹配提示

### 3.2 侧边栏导航（Sidebar）
- **分组管理**：功能划分为“智能研究”、“知识管理”、“魔法实验”、“笔记灵感”四大组。
- **智能收起**：
  - 展开时：完整展示所有菜单项，支持分组折叠。
  - 收起时：仅展示分组图标，悬停图标可浮出二级菜单，保持界面整洁。
- **章节管理**：支持章节拖拽排序、新建、重命名与删除。

### 3.3 全局搜索（Search）
- 支持章节与参考文献的统一搜索
- 结果高亮与上下文片段展示
- 点击可直接跳转到对应内容

### 3.4 参考文献管理（Bibliography）
- 题录 CRUD（新增、编辑、删除）
- 规范化引用格式预览
- AI 解析参考文献文本并自动填充表单
- 附件上传 + OCR 自动抽取全文（PDF 转 Markdown）
- 参考文献笔记与附件管理

### 3.5 论文阅读（Papers）
- 从参考文献中读取全文，统一展示在论文列表
- 论文阅读支持 Markdown 渲染 + 思维导图
- 论文笔记管理
- 选中文本的 AI 操作与高亮管理

### 3.6 知识体系（Knowledge）
- 按模块维护知识点
- 支持列表 / 时间轴 / 热力图三种视图
- 知识点详情页：定义、关系、笔记、多媒体附件
- AI 自动生成知识点关系与解释

### 3.7 灵感与素材（Inspirations）
- 灵感记录、编辑、标签化
- 关联引用、笔记、知识点
- AI 生成段落或论文草稿
- 支持图表/插图生成（SVG）

### 3.8 高亮与摘录（Highlights）
- 汇总所有章节/论文的高亮
- 支持批量复制、批量删除
- 支持备注与来源引用
- **跳转原文**：点击高亮项可直接跳转至对应的 PDF 阅读器或章节位置

### 3.9 笔记中心（Notes）
- 集中查看章节/参考文献/知识点笔记
- 搜索与快速跳转

### 3.10 语音速记（Voice Memos）
- 浏览器录音并上传
- 语音转文字（需配置语音 API）
- 一键转换为学术风格文本

### 3.11 内部动态（Weibo）
- 研究过程记录：发布、评论、转发
- AI 主编智能评论
- 多个功能会自动发帖（如新增文献、上传论文等）

### 3.12 Corkboard 章节概览
- Scrivener 风格卡片墙
- 每章可维护摘要与状态
- 一目了然的结构化写作进度

### 3.13 中转站（Transfer Station）
- 跨模块素材暂存与搬运
- 方便在章节、文献、灵感之间流转内容

### 3.14 发现页（Discovery）
- 聚合学术发现与推荐
- 辅助拓展研究视野

### 3.15 研究看板（Research Board）
- **多维度视图**：
  - **大纲视图（Tree）**：无限层级递归结构，理清研究脉络
  - **看板视图（Kanban）**：按状态（待研究/研究中/已完成）管理进度
  - **标签视图（Tags）**：按标签聚类概念，支持磁贴展示与标签重命名
- **概念管理**：支持无限级子概念、Markdown 备注、自定义标签（颜色/名称）
- **关联体系**：每个概念可关联具体的参考文献、知识点或灵感
- **交互优化**：新增节点自动定位高亮、拖拽移动节点、标签全局批量重命名
- **状态追踪**：可视化展示每个研究点的完成度

### 3.16 深度研究（Deep Research）
- 专注于复杂课题的深度探索空间。
- 提供沉浸式研究界面（无边框全屏模式）。
- 具体功能视实现细节而定（待补充）。

### 3.17 词性洞察（Word Insight）
- **多维图表分析**：
  - **词云（Word Cloud）**：直观展示高频关键词。
  - **柱状图（Bar Chart）**：对比词频分布。
  - **饼图（Pie Chart）**：展示词性占比。
  - **树图（TreeMap）**：层级化展示关键词结构。
- **智能筛选**：
  - **来源过滤**：可按全部、参考文献、论文、或混合模式筛选语料来源。
  - **词性过滤**：支持名词、动词、形容词、实体、副词等多维度筛选。
- **关联分析**：
  - **共现关系**：展示选中词汇的共现词网络。
  - **历时趋势**：通过年份轴展示关键词在文献中的出现频率变化。
  - **上下文溯源**：点击关键词可直接查看原文中的上下文片段。

## 4. AI 与外部服务配置

### 4.1 AI Key 配置
在「魔法管理（Magic）」页面配置：
- DeepSeek API Key（用于润色、扩写、抽取、知识关系、灵感生成等）
- 语音识别 Volcengine Key/Secret（用于语音转写）
- OCR 服务（PaddleOCR API 地址与 Token）

### 4.2 魔法按钮（Magic）
可自定义常用 AI 操作模板：
- 提取参考文献
- 学术润色
- 术语解释
- 内容扩写

---

## 5. OCR 与全文处理

### 5.1 上传 PDF
- 在参考文献详情页上传 PDF
- 后端启动 OCR 任务
- 前端自动轮询进度
- OCR 完成后生成 Markdown 全文

### 5.2 使用场景
- 论文全文快速导入
- 章节引用时直接搜索全文内容

## 6. 常见工作流示例

### 示例 1：撰写新章节
1. 侧边栏点击“+”新建章节
2. 在 Reader 中编写 Markdown
3. 使用参考文献面板插入引用
4. 通过 AI 菜单润色/扩写段落

### 示例 2：文献入库 + OCR
1. 在 Bibliography 新建文献
2. 上传 PDF
3. OCR 完成后进入 Papers 阅读全文

### 示例 3：构建知识体系
1. 在 Knowledge 中建立模块与知识点
2. 通过 AI 自动关联知识点
3. 使用时间轴或热力图检查分布

## 7. 只读外部 API

本项目提供一套只读 API，方便外部工具（如 AI 写作助手）检索知识库与文献：

基础地址：`http://localhost:3001/api/external`

包含：
- 文献检索（支持全文深度搜索）
- 文献详情
- 知识点检索
- 灵感列表

详情请查看 API 文档：`API_DOCS.md`

## 8. 常见问题

### Q1: 前端加载不了数据？
- 确保后端 `npm run server` 正在运行
- 检查端口 `3001` 是否被占用

### Q2: OCR 一直停在处理中？
- 确认已正确配置 PaddleOCR API
- 查看后端日志是否有错误

### Q3: AI 功能无响应？
- 检查 DeepSeek Key 是否有效
- 确认网络能够访问外部 API

## 9. 目录结构速览

```
treatise/
	src/
		components/    # 前端组件（Reader、Sidebar、Knowledge 等）
		content/       # 章节内容（Markdown 文件）
		data/          # 系统数据（JSON）
		               #   chapter_meta.json, references.json,
		               #   knowledge.json, inspirations.json,
		               #   highlights.json, weibo.json 等
		utils/         # 工具函数（录音、引用格式化、自动发帖等）
		scripts/       # 辅助脚本（OCR 转换、NLP 分析等）
		assets/        # 前端静态资源
	public/
		papers/        # 论文 PDF 与转换后的内容
		knowledge/     # 知识点附件
		assets/audio/  # 语音记录文件
	server.js          # 后端服务入口（Express 5）
	vite.config.js     # Vite 构建配置
	tailwind.config.js # Tailwind CSS 配置
	API_DOCS.md        # 只读外部 API 文档
```
